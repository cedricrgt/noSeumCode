Absolument ! Le Pack Starter est spécialement pensé pour les débutants complets. Nous partons de zéro : installation de VS Code, balisage HTML pas à pas, puis mise en page CSS progressive.

Puis-je évoluer vers le Pack Web complet plus tard ?

Oui ! À la fin de tes 6 semaines Starter, tu peux basculer sur le Pack Web pour aborder JavaScript et les projets dynamiques, en déduisant simplement le montant déjà versé.
