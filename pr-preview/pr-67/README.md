# NoSeumCode - Site E-Learning

Site web moderne pour la plateforme d'apprentissage du code NoSeumCode.

## 🚀 Démarrage Rapide

Ouvrez simplement `index.html` dans votre navigateur :

```bash
open index.html
```

Ou utilisez un serveur local :

```bash
# Avec Python
python3 -m http.server 8000

# Avec Node.js
npx serve
```

## 📋 Fonctionnalités

- ✨ Design moderne avec gradients et animations
- 🎨 Palette de couleurs vibrante (vert néon + dark navy)
- 🎭 Effets interactifs (3D tilt, ripple, smooth scroll)
- 📱 Responsive design (mobile, tablet, desktop)
- ⚡ Performance optimisée
- 🎯 Slider infini de technologies

## 🎨 Technologies Utilisées

- **HTML5** - Structure sémantique
- **CSS3** - Animations et gradients
- **JavaScript** - Interactivité
- **Google Fonts** - Poppins & Bangers
